🔐 登录后台

首次使用将注册管理员账号，后续编辑需登录。

提示：账号保存在你的 Cloudflare D1 数据库中（免费额度），密码加密存储。 若这里显示“未配置后端”，请查看 README 的账号系统部署教程。

🔑 GitHub Token 登录

当前为纯静态部署（无后端），使用 GitHub Token 直接读写仓库里的 links.json。

如何创建 Token：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → 仅选择本仓库 → Repository permissions → Contents 设为 Read and write。
